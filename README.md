# WebManufaktur

Website von WebManufaktur (Anton Schlereth).

## Struktur

```
index.html      Die komplette Website
images/         Bilder, hier liegt das Logo (logo.png)
```

## Logo einbinden

1. Logo als `logo.png` in den Ordner `images/` hochladen
2. Fertig – die Website zeigt es automatisch im Kopfbereich an

Wenn du lieber eine SVG-Datei verwendest, ändere in `index.html` den Pfad
`images/logo.png` in `images/logo.svg`.

## Veröffentlichen mit GitHub Pages

1. Repository auf GitHub öffnen → **Settings** → **Pages**
2. Unter „Branch" `main` und Ordner `/ (root)` wählen → **Save**
3. Nach kurzer Zeit ist die Seite unter `https://<dein-benutzername>.github.io/<repo-name>/` erreichbar
